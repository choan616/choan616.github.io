# 건망증 방지 상황별 체크리스트 서비스 (YouDid)

이 프로젝트는 건망증이 있는 노인 및 성인 사용자를 위한 직관적이고 쉬운 체크리스트 서비스입니다.

## 주요 기능
- 상황별(외출 전, 취침 전 등) 체크리스트 프리셋 로드
- "했어!" / "아직" 터치 및 클릭 피드백
- 노안을 고려한 큰 글자 크기 및 글래스모피즘 기반의 미려한 UI
- 항목 선택 시 음성 안내(TTS) 기능
- 브라우저 로컬 저장 기능 (`LocalStorage` 사용)

## 구조
- `index.html` : 마크업 구조
- `index.css` : 모던 스타일링 및 반응형 레이아웃
- `app.js` : 비즈니스 로직 및 로컬 스토리지 데이터 관리
