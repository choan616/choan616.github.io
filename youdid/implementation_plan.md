# 스피커 버튼 제거 및 카드 내부 레이아웃 세로 정렬 구현 계획

점검 카드 내부의 우측 스피커 아이콘을 완전히 제거하고, 텍스트가 가로폭을 최대한 넓게 사용할 수 있도록 카드 텍스트와 상태 배지의 배치를 세로 정렬(`flex-direction: column`)로 전환합니다.

## User Review Required

> [!IMPORTANT]
> **카드 레이아웃 정렬 개편**
> - **스피커 버튼 삭제**: 
>   - 카드 우측을 지키고 있던 스피커 아이콘(🔊)을 삭제하여 텍스트 표시 영역을 넓힙니다. (상황 안내나 전체 완료 음성 안내 기능은 그대로 활성화되어 있습니다.)
> - **텍스트 & 배지 세로(Column) 정렬**: 
>   - 기존 `[텍스트] ------ [배지]` 가로 정렬 방식에서, 위쪽에 `[점검 텍스트]`, 아래쪽에 `[상태 배지("했어!" / "아직")]`가 오는 세로 flex 정렬로 변경합니다.
>   - 이를 통해 점검 문항 텍스트가 좌우로 끝까지 뻗을 수 있어 가독성이 획기적으로 상승합니다.
